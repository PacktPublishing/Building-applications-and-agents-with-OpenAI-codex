# Chapter 10 · Lab 11: Visualize a Multi-Agent Handoff Architecture

## Goal

Describe a multi-agent workflow with real OpenAI Agents SDK `Agent` objects and
two successive handovers, then draw and export the architecture as a PNG with
the SDK's `viz` extension.

## What You Build

- An intake agent that hands a request to a research agent.
- A research agent that hands findings to a response writer.
- A local PNG diagram generated by `agents.extensions.visualization.draw_graph`.

The three-agent chain contains exactly two directed handover edges. Creating
and exporting the diagram makes no model or API calls.

## Checkpoint

Run the exporter, open `reference-solution/outputs/multi-agent-handoffs.png`,
and confirm the diagram shows both handover arrows and the start/end nodes.
